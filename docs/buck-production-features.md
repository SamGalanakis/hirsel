`tools/buck2/production-features.json` classifies every declared workspace feature and lists the exact existing leaks per production root. `sync.py` checks that inventory and follows the generated normal and build-script edges whenever it regenerates first-party rules. A newly leaked or unclassified feature fails generation; a resolved exception must be removed. Thus the ordinary sync/land screen accepts only the documented baseline, not production isolation.

Run `python3 tools/buck2/sync.py --if-stale --strict-production-features` to reject all baseline leaks as well. Today this fails on 12 compiler and four archive-dependency feature pairs. The installed bundle, std producer and checked/release/dist compilers share the same generated features. Explicit diagnostic, measurement, sanitizer and ownership runtime variants remain deliberate selections; the audit checks their common dependency graph. Third-party features are not covered by this first-party inventory.
