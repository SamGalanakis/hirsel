## Doctrine and preservation checks

`CONTEXT.md:16-28,43-56` confirms stable Task identity, Anchor/mentions, one global conversation, constrained instruments and current terminology. ADR-0004's clarification permits visible Tasks while rejecting host execution/retry machinery; its historical no-table statement requires reconciliation if the representation changes. ADR-0009 specifies Open/Done, lifecycle-neutral conversation, and explicit action settlement. ADR-0012 retains typed Events as Task wire/storage and its historical awareness dismissal rule; changing those requires an explicit update. ADR-0013 preserves same-ID continuing stages. ADR-0010 requires native Task Margins while accepting feature lag. The prompt's result-publication guidance and stale reply-resolves/@name instructions are present at the cited `prompts/agent.md:12,33,45-51`.

Existing same-ID recompose/complete/reopen test assertions (`crates/hirsel-host/src/tests.rs:450-526`) and archive/Undo/idempotence assertions (`storage/events/tests.rs:69-176`) match the briefs. They were inspected, not run. Proposed new commands, schemas, TaskActivity representation and test matrix are design recommendations, not existing implementation facts. The synthesis correctly retains Owner settlement authority and calls attention updates outside action turns a producer-contract extension.
