# SHA-512

[API overview](../API.md). [Operations and contracts](../sha512.hirsel).

`sha512.hash(bytes)` returns the 64-byte, big-endian FIPS 180-4 digest.
Use `start()` to create a `Sha512` state or `start_from(h)` to supply eight
initial `u64` words. `add(mut state, bytes, lo, hi)` appends the checked range
`[lo, hi)`, and `add_byte(mut state, byte)` appends a single byte.
`finish(state)` returns the digest and leaves the state usable for more input.

The state holds the chaining words, a 128-byte pending block, and the byte
count. Finalization encodes the bit count in a 128-bit big-endian field, exact
for total lengths below 2^64 bytes. The operations allocate nothing and
retain no input views. `add` fills the pending block, copies the trailing bytes,
and passes the intervening complete blocks to the kernel in one call.

The module extends core's `sha512`, whose `blocks` and `block` compress whole
blocks. The runtime selects SHA-512 instructions when supported and uses the
portable rounds otherwise. Set `HIRSEL_SHA512=portable` to force those rounds.
Both paths produce the same state words. [Core specification](../../../docs/spec/core.md#sha-512).
