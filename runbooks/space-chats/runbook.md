# Space chats product runbook

Follow [`../RULES.md`](../RULES.md). This is a bounded real-provider check; run it only with explicit approval.

Verify route-free entry restores the last active top-level Space, falls back to the first by ID, and creates Home through ordinary creation only when none exists. Explicit bad links must remain unavailable. The composer labels its recipient and identifies a Task recipient as a worker.

From a Task, **Talk about this** must return to its Space chat and draft `#<task-id>`. The accepted message contains the mention but no focus snapshot. **Step in** addresses the worker; while it runs, Stop and **Send after current turn** remain separate.

Ask the Space chat for one tiny verifiable change. It must delegate to a Task and remain responsive. Verify the worker reports a concise result and the Space chat produces a standalone answer. Retain sanitized screenshots, frames, Thread snapshots and the advertised tool catalog; never retain credentials.
