## Rejected and narrowed coordinator dispositions

The rejected proposals do not need replacement recommendations. In particular:

- **C02 Host preference freezing: uphold reject.** Reopened `thread_execution.rs::capture` and `scoped_tools.rs::resolve_assignment`. CLI preferences are reused; Host captures current host_execution_default per newly accepted turn. The tool explicitly rejects Host model selectors. Immutable accepted-turn settings do not imply immutable settings across later turns. Freezing copied Host metadata changes policy and can retain unavailable provider configuration.
- **C03 reverse receipt uniqueness: uphold reject and factual correction.** Reopened chat reverse lookups, transactional message/receipt insertion and the local rusqlite 0.37.0 source at lib.rs:647–648: query_row ignores rows after the first. No present writer maps two receipt IDs to one message. A schema-permitted hypothetical ambiguity is not the claimed failing read. Duplicate mentions can repeat short labels, not duplicate conversation expansion; a relational rewrite neither bounds input nor earns the cross-layer churn.
- **C08 subagent Process restoration: uphold reject.** Rust ProcessKind has only Monitor; PRODUCT/ADR0015 put CLI work in Thread execution. Stale TS branches are not a mandate for a second inventory. F08 requires neither a last_wake timestamp nor restoration of a producer.
- **C01 nested action identity and C05 receipt denormalization: uphold skip.** Action context captures the Thread fetched by the outer ID; delegation inserts child and accepted turn together in one transaction. No split update witness. Historical snapshots remain meaningful; deleting the delegation scalar buys joins in replay paths and a schema cutover, not current correctness.
- **C06 artifact metadata union: uphold skip.** Kind chooses preview, MIME/download name are authored metadata. PRODUCT/ADR0017 do not establish one invariant merging them. Preserve mutable global content, independent references/grants and scoped backlinks; do not introduce artifact versions or ownership.
- **C07 malformed Related parity: uphold skip.** Native's item-owner guard is stronger, but current host source-filtered snapshots do not produce the fabricated mismatch. Keep native flat-state ownership and web captured-history invalidation; no generalized receiver validation project.
- **C09/C10 driver parser/identity redesigns: uphold skip.** Reopened Codex receive/control timeout/fail and Claude root/request correlation. Codex timeout drains pending waiters and kills its group; independent server-request IDs are intentional. Fabricated frames and unspecified Claude sessionless-event rules do not support a broad union/phase cutover. Existing #2–6 remain excluded.
- **C13 roster unions and C21 public client configuration union: uphold skip.** Current producers construct coherent snapshots/configurations; invalid cross-products alone do not show material current branching or divergence. F11 and F02 have real supported producers and remain distinct.
- **C16 artifact source preference/sandbox module, C20 theme owner, C23 plugin reconciler/ID redesign, C24 unused cache and C26 blanket lock policy: uphold nonmaterial dispositions.** Respect current preview policy and panel preference; no installed plugin implementation establishes current user impact. The cache is redundant but not serving stale data. Do not expand small constant/dead-code observations into new modules. F23 differs because two active build recipes already maintain the same outputs separately.
