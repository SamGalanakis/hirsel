# SHA-384

[API overview](../API.md). [Operations and contracts](../sha384.hirsel).

`std.sha384.hash(bytes)` returns the 48-byte, big-endian FIPS 180-4 digest.
`start()` creates a `Sha384` state. `add(mut state, bytes, lo, hi)` appends the
checked range `[lo, hi)`, and `add_byte(mut state, byte)` appends one byte.
`finish(state)` returns the digest and leaves the state usable for more input.

SHA-384 uses the [SHA-512 compression kernel](sha512.md), its own initial
state words, and the first 48 bytes of its final state. The operations
allocate nothing and retain no input views.
