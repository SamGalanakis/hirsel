# Thread concept gallery

This standalone design exploration presents three generated raster mockups. It does not change the application design contract.

The gallery is an image-led comparison surface: a quiet graphite surround, a compact option selector, a large uncropped image, and short concrete tradeoffs. System sans serif inherits the incumbent application language. Muted sage marks the selected option. Navigation and image controls remain usable at phone widths. Full-size images open separately for close inspection.

A Conversation makes correspondence primary. B Journal combines conversation and meaningful milestones. C Workbench gives the current result most of the screen and keeps discussion alongside it. All examples show one interlocutor, durable Threads, optional planner provenance and no worker assignments.
