Primary-source inspiration

What was borrowed, and what was refused

Hirsel ADR-0013

Every Task or View may carry a validated constrained JSON component tree.

This is product truth, not visual inspiration: one renderer across Task instrument and Canvas, with semantic tokens and structured actions.

Hirsel ADR-0008 · historical

Recorded isolated Side Chats and is now superseded for visible product UI.

Task Margins removes that boundary: Task conversation informs global Hirsel while it happens.

Dynamicland

Computational objects are visible, local, and responsive rather than hidden behind applications.

Borrow conversation living in the task. Refuse literal physical-object skeuomorphism.

Ink & Switch Embark

One living document gradually gains structure and computation as needed.

Borrow enrichment in place. Refuse an outline or canvas users must manually maintain.

Google Generative UI

Interfaces can be composed around the immediate intent instead of selected from a fixed application catalog.

Borrow task-specific generation. Refuse arbitrary generated HTML and visual drift.

Block Buzz

Mutate-in-place action cards, deterministic transcript grouping, broadcast replies, steer versus interrupt.

Borrow client-side event grammar. Refuse its multi-user relay architecture and unfinished human approval model.

Stress tests and rejected worlds

Directions that looked exciting but made orchestration harder

EVIDENCE AS A PLACEEvidence may render inside a task’s generated UI, but it never earns its own destination, thread, or level of navigation.
NESTED THREADSA task conversation cannot spawn another conversation surface. Further questions remain in the same task.
ISOLATED SIDE CHATThe existing contract hides a side transcript from the main Agent until conclusion. Global Hirsel must instead be aware while the task conversation unfolds.
SUBAGENT UISpecialists are orchestration internals. They never become correspondents, tabs, avatars, or selectable sessions.
MANUAL TASK SYSTEMNo boards, columns, parent projects, dependency editors, or filing rituals. Hirsel owns task organization.
Decision
Task is the ontology. Generated UI, conversation, events, processes, and artifacts are contents or consequences of a task, not new places in the product.
