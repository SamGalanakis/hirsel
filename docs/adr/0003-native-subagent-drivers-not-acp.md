# Drive Sub-agents over native headless protocols, not ACP

The original design called for the Agent to be a full ACP client with Sub-agents exposed over MCP. We dropped both layers: Sub-agents are driven by native Rust `SubagentDriver` implementations inside the Hirsel Host, speaking each CLI's official headless JSONL protocol directly (Claude Code `stream-json`, Codex `exec --json` / app-server). Rationale: ACP's flagship feature — structured permission brokering — is dead weight in a full-auto system that bypasses permissions at spawn time; and Claude Code only speaks ACP through a Node adapter wrapping the Agent SDK, adding a process layer that lags native features. The `SubagentDriver` trait is the stable seam; an ACP driver can be added later if an ACP-native agent becomes worth supporting.
