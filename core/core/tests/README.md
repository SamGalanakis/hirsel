# Core contract laws

Run these laws with the shared [core and std walker](../../std/tests/README.md).
Use `core.<file-stem>` filters. Private laws begin with `// test-of: core.<module>`;
evaluator-only misuse laws also declare `// test-backend: evaluator` and their
reason. The shared README documents exact oracles, backend targets and reporting.
These files are never canonical library or product inputs.
