# NIST CAVP source

NIST CAVP's byte-oriented SHA release, CAVS 11.0, May 2011.
The files are unchanged from
[shabytetestvectors.zip](https://csrc.nist.gov/CSRC/media/Projects/Cryptographic-Algorithm-Validation-Program/documents/shs/shabytetestvectors.zip)
and retain their original response names and headers. Public domain.
NIST publishes the data as a release archive. Its SHA-256 is
`929ef80b7b3418aca026643f6f248815913b60e01741a44bba9e118067f4c9b8`.

The sample covers single-byte input, the 55/56-byte padding boundary,
the 63/64-byte block boundary, and long messages of 1304 and 9224 bits.
